# Protótipo (versão web no claude.ai)

`data-fox.html` é a versão em página única usada para desenhar e testar o Data Fox,
publicada como artefato no claude.ai. Ela usa os recursos da própria plataforma
(banco, arquivos, login e IA) e não roda fora dela.

Serve como referência de comportamento e visual para a versão Laravel deste repositório.
O backup completo (.zip) gerado nela é importado aqui com `php artisan datafox:import`.
